# Herois_baiduu — Bedrock

Add-on de Minecraft Bedrock com os heróis do mod Herois_baiduu (Java). Começa pelo Flash.

- `BP/` — pacote de comportamento (itens, bloco, receitas, script em `BP/scripts/main.js`)
- `RP/` — pacote de recursos (texturas, armadura, partículas, textos)
- `python3 build.py` gera `dist/Herois_baiduu.mcaddon`

Requer Minecraft Bedrock 1.21.50 ou mais novo.
